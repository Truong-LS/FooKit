## 1. Standard Ingredients Management

This is the core dataset of the entire system. Every processing flow (from Shopee affiliate link matching to AI keyword mapping) revolves around the IDs in this table.

**Authentication:** Required (JWT Token with Admin role required).

### Designed Endpoints

#### `GET /api/admin/ingredients`

**Query Parameters:**

* `page`
* `size`
* `search` (search by ingredient name)
* `category` (meat, vegetables, spices, etc.)

**Response:**
Returns a paginated list of ingredients.

---

#### `POST /api/admin/ingredients`

**Purpose:**
Add a completely new ingredient into the system.

---

#### `PUT /api/admin/ingredients/{id}`

**Purpose:**
Fix spelling mistakes or change the ingredient category.

---

#### `DELETE /api/admin/ingredients/{id}`

### Extremely Important Backend Processing Flow

Do **not** use `Remove()` immediately.

The backend must first check whether this ingredient ID is already being used in the `AffiliateProduct` or `IngredientDictionary` tables.

* If it is being referenced, deletion must be blocked and a `400 Bad Request` error should be returned.

Example:

```json
{
  "message": "Cannot delete because there are currently 3 Shopee affiliate links associated with this ingredient."
}
```

For maximum safety, you should implement an `IsDeleted` column (Soft Delete) for this table.

# 2. AI Dictionary Cache Management

This is where the Admin acts as the “teacher” correcting AI mistakes. If the AI maps the wrong ingredient ID, the final results shown to users will be completely inaccurate.

**Authentication:** Required (JWT Token with Admin role required).

### Designed Endpoints

#### `GET /api/admin/ai-dictionary`

### Query Parameters

* `page`
* `size`
* `search_raw_text` (search by raw English keyword)

---

#### `PUT /api/admin/ai-dictionary/{id}`

**Purpose:**
Correct the mapping to the proper ingredient.

### Request Body

Pass the `new_standard_ingredient_id` (the ID of “Apple”).

### Backend Processing Flow

Find the dictionary record by `id`, then update the `StandardIngredientId` column with the new value.

---

#### `DELETE /api/admin/ai-dictionary/{id}`

**Purpose:**
Completely remove this English keyword from the cache.

### Objective

The next time a user searches for a recipe containing this keyword, the system will be forced to send the keyword back to Google Gemini/OpenAI so the AI can analyze and remap it from scratch.

# 3. Affiliate Links Management

Allows you to manually intervene in the automation system. Sometimes the worker may find a correctly named product link, but the shop has terrible reviews — you need the ability to immediately “eliminate” that link.

**Authentication:** Required (JWT Token with Admin role required).

### Designed Endpoints

#### `GET /api/admin/affiliate-links`

### Query Parameters

* `page`
* `size`
* `is_active` (filter enabled or disabled links)
* `ingredient_id` (view all links associated with a specific ingredient)

---

#### `PUT /api/admin/affiliate-links/{id}/toggle-status`

**Purpose:**
Enable or disable a specific affiliate link.

### Request Body

No body is required, or you can send a small JSON payload:

```json
{
  "is_active": false
}
```

### Backend Processing Flow

Use EF Core to find the corresponding record in the `AffiliateProduct` table by `id`.

Update the `IsActive` field to `false` (or `true` if re-enabling the link), then call `SaveChangesAsync()`.

From that moment onward, the Meal Recommendation API on the homepage will automatically ignore this affiliate link when calculating meal pricing.
